Privacy policy

Last updated: 13 November 2026

What this covers

This policy covers the GetClever2 uploader, a private application that publishes videos to the GetClever2 YouTube channel using YouTube API Services. The application is used only by the owner of the GetClever2 channel. It is not available to the public and has no other users.

YouTube and Google

The GetClever2 uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the application accesses

  • Upload access (YouTube scope youtube.upload): used only to upload videos that the channel owner produced, with their title, description and tags.
  • Read-only channel information (YouTube scope youtube.readonly): used only to confirm which channel a login belongs to before uploading (channel name, ID, subscriber and video counts).

The application does not access, collect, store or share data about viewers, commenters or any other YouTube users.

How data is stored

The OAuth access token that Google issues is stored only on the channel owner's own computer, in a file readable by that user alone. It is never transmitted anywhere except to Google's own servers when calling the YouTube API. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google account's security settings: security.google.com/settings/security/permissions. Revoking deletes the application's ability to act on the channel immediately.

Contact

Questions about this policy can be raised on the project's GitHub page: github.com/eheimbuerge90-web/getclever2-site.
